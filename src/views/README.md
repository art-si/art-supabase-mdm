# MDM views

MDM 维护跨业务域主数据的统一目录、质量治理、四眼变更、黄金记录和可靠事件交付。来源应用仍是业务主档的权威写模型；治理中心只通过数据库授权 RPC 生成审批记录和 Outbox 指令，由来源适配器幂等执行，避免双写。

## BOM 维护与删除

BOM 维护列表只允许勾选有删除权限且处于设计状态的 BOM。批量删除通过 `mdm_delete_boms(uuid[])` 在一次事务内逐条调用 `mdm_delete_bom(uuid)`；任一条失效或被业务引用时整批回滚。单条与批量删除共用服务端的按钮权限、当前租户范围和设计状态校验。删除函数先移除组件，再删除父 BOM，保证组件删除触发器能读取到父项；配件加工清单仍引用该 BOM 时明确拒绝删除。

2026-09-30 在项目 `ckbftoopuyophiebamwy` 的回滚事务验证了平台全部租户、平台选定租户、普通用户本租户删除，以及普通用户伪造跨租户请求被拒绝、非设计状态和业务引用被拒绝、批量失败整批回滚。应用函数后重复验证，BOM 与组件数量保持 15/60，未留下测试删除。

## 配件加工清单

工程主数据的“配件加工清单”以项目、图纸和独立加工件为主线。页面沿用业务工作区头部、分割面板、`ArtSectionCard` 和 `ArtTable`：左侧树按系统项目和图纸筛选，支持搜索、展开及面板拖拽收缩；右侧展示逐件明细。表格使用 `ArtTable` 内置分页，默认每页 20 件；宽分栏显示总数、页码、每页条数和跳页，窄分栏按实际宽度收紧，分页栏始终留在明细面板底部；换页后序号延续且滚动回顶部。图片列保留足够宽度完整展示 64 × 56 的预览或待补图占位。宽屏时操作按钮、编码状态筛选和搜索框位于同一行；窄屏时操作区可横向滚动，筛选与搜索保持可见。选中记录后说明置灰操作的业务条件，并提供“查看待编码件”入口。专注模式隐藏概览，按 Esc 退出。图纸项目名称保留识别或手工录入值，系统项目通过 MDM 销售项目关联，两个字段独立保存。

手工新增、复制、编辑和删除经过各自的 `MdmAccessoryProcessing` 按钮权限与租户范围校验。手工清单的 `source_path` 为 `null`；上传图片与 MDM 物料编码共用 `ArtUploadImage`、资源库和 `sys_attachment`/`attachments` 存储，图片 URL 保存在加工件 `image_urls`，生成编码时同步到 `mdm_material.image_urls`。AI 识别支持 PNG/JPG/WebP、PDF、DOCX 和统一模板，原件存入 `mdm-accessory-processing` 私有桶，浏览器最多栅格化前三页、文件上限 20 MB；同一原表行的不同长度拆为独立加工件。租户用户可识别并查看本人识别审计记录；保存 AI 结果及后续修改、生成物料、BOM 或工单均按对应按钮权限与租户范围控制，无须平台超级管理员身份。识别记录须经人工校对并点击“保存配件加工清单”才进入业务列表。

保存草稿时 `material_code` 与物料描述为空，`code_rule_id` 指向目标租户的有效策略。默认物料类型为“半成品”、来源为“自制”、分类为“配件”，单位优先 PC/件；用户可按目标租户有效选项调整。`mdm_generate_accessory_materials` 沿用 MDM 物料编码规则生成 `mdm_material`，将编码、描述和图片关联回加工件。已编码件需先通过“删除物料编码”解除关联，才可编辑并重新生成。单选或多选“删除”会在一个事务中删除加工件及其未被引用的物料；“删除物料编码”只删除所选物料，保留加工件、图片并重置为待编码。两项操作复用 `MdmAccessoryProcessing:Delete` 按钮权限，一批最多 100 件；如任一物料已有 BOM、MES 工单或其他业务引用，整批拒绝且不发生部分删除。`mdm_generate_accessory_processing_stage(..., 'bom')` 根据已编码清单创建项目 BOM。原有一键生成及旧材料/工单阶段保留兼容权限，但数据库拒绝旧阶段执行，避免写入旧加工单表。

“转生产工单”调用 `mdm_convert_accessory_work_orders`，按所选已编码加工件分别写入 `mes_work_order` 和 `mes_work_order_detail`；工单类型固定为 PP40，系统项目自动带入，计划开始日期默认为当天，完工日期必填，施工号可空且不要求预存施工段。`mes_work_order.accessory_item_id` 建立来源关联并以租户和加工件唯一约束防止重复转单。列表“是否转工单”根据该 MES 关联显示状态。旧 `mdm_accessory_work_order` 历史记录不充当 MES 转单状态。

数据库变更在 Supabase 项目 `ckbftoopuyophiebamwy` 通过受控 SQL 事务执行，增补了清单来源可空、加工件编码策略、图片 URL 和 MES 加工件来源关联。业务表直接写入仍受 RLS 限制；公开 RPC 为 `SECURITY INVOKER`，内部授权函数在 `app_private` 校验登录、按钮权限和目标租户。2026-09-30 的回滚事务验证了普通租户用户手工新增、保存 AI 草稿、复制与编辑、生成 MDM 物料、转项目 BOM、生成 PP40 MES 工单、批量删除、删除编码后重新生成，以及图片回填；另验证 BOM 引用阻断时整批回滚。事务结束后没有留下测试业务数据。

历史识别验证：2026-09-28 的真实雨篷样张在三页中识别出 6 个有内容行，同一行的 2.7 m 和 4.8 m 保持为两个加工件。草图边界不可信时返回 `null`，需要人工补图与核对；`ai-accessory-processing-contract.test.ts` 覆盖长度拆分及无效行。

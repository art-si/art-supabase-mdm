## 项目定位

亿企工场 MDM 是亿企工场的主数据治理与生产基础配置应用。它一方面把分散在 Platform、HR、TMS、VMS、SMIS 等来源中的关键主档汇入统一只读目录，提供一致的查询、质量识别和来源追溯；另一方面维护生产组织、人员、日历、标准作业、工作中心与工艺路线，为 MES 等执行应用提供稳定的生产语义。

本仓只维护 MDM 页面、业务 API、领域类型与生产基础规则。认证、租户、菜单、权限、布局、路由、公共组件、Store 和 Supabase 公共客户端由 [`art-supabase-pro`](https://gitee.com/wangyanghub/art-supabase-pro) 统一提供。

## 核心能力

| 领域 | 当前覆盖 |
| --- | --- |
| 治理工作台 | 五类治理域概览、记录与来源统计、资料待完善提醒 |
| 统一目录 | 24 类独立主档与 2 类关系/明细对象、服务端分页、组合筛选、生命周期、完整度、来源追溯与详情核对 |
| 生产组织人员 | 部门/产线树、生产人员配置、最小字段员工参选、导入导出与权限隔离 |
| 工厂日历 | 班次、休息区间、跨午夜、轮班模式、批量排班、参考模式与覆盖缺口提醒 |
| 标准作业 | 作业模板、任务清单、评分、复制及工作中心/工艺工序绑定 |
| 资源与工艺 | 工作中心、人员与设备配置、生产规则、常用配置、二维码及工艺路线 |

## 主数据治理边界

```text
Platform / HR / TMS / VMS / SMIS 权威主档
  → 租户隔离的只读治理契约
  → MDM 统一目录、质量识别与来源追溯
  → 返回来源应用完成主档维护
```

统一目录不制造第二套写入口。组织、员工、客户、承运商、车辆、设备、物料等既有主数据仍由来源应用维护；MDM 负责统一查看和治理提示，不按名称或编号自动合并业务记录。

生产扩展数据由 MDM 自己维护，包括生产部门、生产人员、工厂日历、作业模板、工作中心和工艺路线。它们属于生产基础配置，不等同于 HR 员工、SMIS 设备等来源主档，也不会反向覆盖来源数据。

截至 2026-09-08，统一目录覆盖五类治理域、24 类独立主档，并辅助查看员工任职和客户地址 2 类关系/明细对象。`app_private` 中由数据库维护的数组引用索引只用于完整性约束，不是独立主档，也不作为客户端写入入口。事故人员、培训参与人员、试卷题目等历史快照继续保留发生时事实，不会为了去重改成实时主档引用。

## 生产基础主线

```text
生产部门 / 产线
  → 生产人员与权限范围
  → 班次、轮班模式与工厂日历
  → 标准作业模板
  → 工作中心、人员、设备与执行规则
  → 产品工艺路线与工序绑定
  → MES 计划、派工、报工与追溯
```

MDM 只定义可复用的生产基础和执行契约。生产订单、现场派工、机器采集、报工、质检与完工记录属于 MES 执行范围，不在本仓生成虚构任务或实绩。

## SCM、MES 与 WMS 的共用前置资料

- 仓库定义：启用仓库并维护所属组织、仓库类型和业务应用范围。启用库区与启用仓位可按业务场景分别配置；启用仓位时，实际出入库还需有可用仓位。MES 工单领料仓库的业务范围必须包含「拣货」。
- 物料与编码：采购、工单、发货通知和库存批次应引用同一租户内有效物料；批次或序列号管理由物料主数据决定，业务单据不能临时改变其身份规则。
- 生产与项目：MES 工单使用有效组织、工单类型和 BOM / 工艺资料；有项目归属的采购、领料、完工入库及销售出库应保持项目与施工号一致。

## 独立运行

环境要求：Node.js `>= 22.0.0`、pnpm `>= 11.9.0`。

```powershell
pnpm install
pnpm dev
```

默认访问 `http://localhost:3017`。

```powershell
pnpm check
pnpm build
pnpm preview
```

生产构建输出到 `docs/`，默认公共路径为 `/art-supabase-mdm/`，可作为 Pages 发布目录。

## 与主仓协作

MDM 业务修改在本仓提交并推送，随后在主仓更新 `modules/art-supabase-mdm` 子模块指针。跨模块读取必须经过用途明确、字段最小化、租户隔离的 API/RPC 契约；本仓不直接导入其他业务仓源码，也不复制主平台公共运行时。

## 安全原则

- 普通用户只能读取当前租户及授权范围内的治理目录和生产基础数据。
- 统一目录只读不代表来源数据公开，字段投影仍按业务用途和权限最小化。
- 生产配置的新增、修改、复制、绑定与状态变化必须同时经过按钮权限和服务端校验。
- 页面可见不代表后端授权，数据库 RLS、RPC 校验和引用完整性约束是最终边界。
